# Data dictionary

_Generated by `python scripts/generate_data_dictionary.py` from the dbt schema files and the Gold tables written by Python; do not edit by hand._

Layers: **bronze** (raw, loaded by dlt) -> **silver** (cleaned views and scored articles) -> **gold** (facts, dimensions and forecasts). dbt materialises silver/gold into the `public_silver` / `public_gold` schemas; Python writes `silver.silver_sentiment_scores` and the `gold` forecast tables.

## Bronze and scored sources

### `bronze.raw_matches`

Raw Premier League match data from football-data.org API

| Column | Description |
|---|---|
| `id` | Match ID from football-data.org |
| `matchday` | Matchweek number (1-38) |
| `home_team_name` | Home team name as returned by the API |
| `away_team_name` | Away team name as returned by the API |
| `home_team_id` | Home team ID from football-data.org |
| `away_team_id` | Away team ID from football-data.org |
| `score_home` | Goals scored by home team (null if not played) |
| `score_away` | Goals scored by away team (null if not played) |
| `status` | Match status: SCHEDULED, LIVE, IN_PLAY, PAUSED, FINISHED, etc. |
| `utc_date` | Match kickoff datetime in UTC |
| `season` | Season start year (e.g. 2026) |

### `bronze.raw_news_articles`

Raw news articles (Guardian, GDELT, RSS fallback) related to PL teams

| Column | Description |
|---|---|
| `url` | Article URL (used as primary key for deduplication) |
| `title` | Article headline |
| `description` | Article summary/description |
| `content` | Article body content (may be truncated by free tier) |
| `source_name` | News source name (e.g. BBC Sport) |
| `published_at` | Publication datetime in ISO format |
| `team_query` | Team name used as the search query |

### `silver.silver_sentiment_scores`

NLP sentiment scores for news articles

| Column | Description |
|---|---|
| `article_url` | Foreign key to silver_news_articles |
| `sentiment_label` | POSITIVE, NEUTRAL, or NEGATIVE |
| `sentiment_score` | Confidence score (0-1) |
| `model_name` | HuggingFace model used for scoring |
| `scored_at` | Timestamp of scoring run |

## Silver models (`public_silver`)

### `silver_matches`

Cleaned and deduplicated PL match data with standardized team names and computed results/points.

| Column | Description |
|---|---|
| `id` | Match ID from football-data.org |
| `home_team` | Canonical home team name |
| `away_team` | Canonical away team name |
| `matchday` | Matchweek number (1-38) |
| `home_goals` | Goals scored by home team |
| `away_goals` | Goals scored by away team |
| `home_result` | W/D/L from home team perspective |
| `away_result` | W/D/L from away team perspective |
| `home_points` | Points earned by home team (3/1/0) |
| `away_points` | Points earned by away team (3/1/0) |

### `silver_news_articles`

Cleaned news articles with standardized team names matching silver_matches.

| Column | Description |
|---|---|
| `article_url` | Article URL (unique identifier) |
| `title` | Article headline |
| `team_name` | Canonical team name (matches silver_matches.home_team / away_team) |
| `published_at` | Publication timestamp |

### `silver_fixtures`

Every fixture of the live season (played or not) with canonical team names and a UTC kickoff time.

| Column | Description |
|---|---|
| `id` | Match ID from football-data.org |
| `match_date` | Kickoff time in UTC |
| `home_team` | Canonical home team name |
| `away_team` | Canonical away team name |

### `silver_article_teams`

One row per (article, team): which clubs an article is about, the sign with which its sentiment counts for each (polarity), and the team's next fixture at publication time.

| Column | Description |
|---|---|
| `article_url` | Article URL (joins to silver_news_articles) |
| `team_name` | Canonical name of a club the article is about |
| `teams_mentioned` | How many clubs the article names (or 1 if it names none and falls back to its search team) |
| `polarity` | +1 sentiment applies as scored, -1 inverted (opponent in a head-to-head article), 0 excluded (round-ups, ambiguous) |
| `next_fixture_id` | The team's earliest fixture kicking off at or after publication (null after the last fixture) |

## Gold models (`public_gold`)

### `dim_team`

Dimension table for all Premier League teams in the 2026-27 season.

| Column | Description |
|---|---|
| `team_key` | Surrogate key |
| `team_name` | Canonical team name |

### `dim_matchweek`

Dimension table for matchweeks with date ranges and completion status.

| Column | Description |
|---|---|
| `matchweek_key` | Matchweek number (1-38), also serves as surrogate key |
| `matchweek_number` | Matchweek number (1-38) |

### `fact_team_sentiment_performance`

Fact table: one row per team per matchweek. Combines match results (W/D/L, goals, points) with news sentiment scores. Includes cumulative standings (running total of points and GD).

| Column | Description |
|---|---|
| `team_name` | Canonical team name (FK to dim_team) |
| `matchweek_number` | Matchweek number (FK to dim_matchweek) |
| `result` | Match result: W (win), D (draw), L (loss) |
| `goals_for` | Goals scored by this team |
| `goals_against` | Goals conceded by this team |
| `points` | Points earned this matchweek (3/1/0) |
| `avg_sentiment_score` | Average sentiment score for this team this matchweek (-1 to +1) |
| `article_count` | Number of news articles about this team this matchweek |
| `cumulative_points` | Running total of points up to this matchweek |
| `cumulative_gd` | Running total of goal difference up to this matchweek |

## Forecast tables written by Python (`gold`)

### `gold.gold_title_predictions`

Latest title-race forecast, replaced on every run of the matchweek pipeline.

| Column | Description |
|---|---|
| `team_name` | Canonical team name |
| `win_probability` | Probability of winning the title (share of simulations won) |
| `avg_final_points` | Mean simulated final points |
| `avg_final_rank` | Mean simulated final league position |
| `simulations_won` | Number of simulations in which the team won the title |
| `total_simulations` | Number of simulations run |
| `top4_probability` | Probability of finishing in the top four |
| `relegation_probability` | Probability of finishing in the bottom three |
| `points_p10` | 10th percentile of simulated final points |
| `points_p90` | 90th percentile of simulated final points |
| `matchweek` | Matchweek of the last played round when the forecast was made |
| `season` | Season start year (2026 = 2026-27) |
| `model_version` | Forecasting model that produced the row (e.g. blend_v3) |

### `gold.title_prediction_history`

Append-only: one set of rows per scored matchweek and model version, so the forecast can be audited as the season unfolds.

| Column | Description |
|---|---|
| `season` | Season start year (2026 = 2026-27) |
| `matchweek` | Matchweek of the last played round when the forecast was made |
| `model_version` | Forecasting model that produced the row (e.g. blend_v3) |
| `team_name` | Canonical team name |
| `win_probability` | Probability of winning the title (share of simulations won) |
| `avg_final_points` | Mean simulated final points |
| `avg_final_rank` | Mean simulated final league position |
| `simulations_won` | Number of simulations in which the team won the title |
| `total_simulations` | Number of simulations run |
| `top4_probability` | Probability of finishing in the top four |
| `relegation_probability` | Probability of finishing in the bottom three |
| `points_p10` | 10th percentile of simulated final points |
| `points_p90` | 90th percentile of simulated final points |
| `scored_at` | When the forecast was written |

### `gold.fixture_predictions`

Forecast for every fixture. Refreshed until kick-off, then frozen, so live accuracy is judged on what was predicted beforehand.

| Column | Description |
|---|---|
| `match_id` | football-data.org match id (joins to bronze.raw_matches.id) |
| `season` | Season start year (2026 = 2026-27) |
| `matchday` | Matchweek the fixture belongs to |
| `utc_date` | Kick-off time (UTC) |
| `home_team_name` | Canonical home team name |
| `away_team_name` | Canonical away team name |
| `p_home` | Forecast probability of a home win |
| `p_draw` | Forecast probability of a draw |
| `p_away` | Forecast probability of an away win |
| `model_version` | Forecasting model that produced the row (e.g. blend_v3) |
| `predicted_at` | When the (latest) forecast was written; frozen once the match is played |
